# Website Editing Guide - LMU Entrepreneurship Society

## 🎯 Quick Start for Content Editors

This website uses **Sveltia CMS** - a user-friendly content management system that lets you edit everything without touching code.

### Accessing the Editor
1. Go to: **https://lmu-entrepreneurship-society.github.io/admin/**
2. Click "Login with GitHub"
3. Grant permissions when prompted
4. You're in! 🎉

## 📝 What You Can Edit

### 1. Site Settings
**Location**: Site Settings → General Settings

**What's editable:**
- **Site Title**: "LMU Entrepreneurship Society" (appears in hero and navigation)
- **Tagline**: "Empowering Student Entrepreneurs" (appears under title)
- **Slideshow Speed**: How fast background images change (in milliseconds)

### 2. Action Buttons
**Location**: Site Settings → Action Buttons

**What's editable:**
- **Button Title**: Text shown on the button
- **Button URL**: Where the button links to
- **Button Icon**: Choose from 10+ professional icons
- **Preview Image**: Image that appears when hovering (desktop only)

**Available Icons:**
- 👥 users (Join Community)
- 📅 calendar (Events)
- 📚 book (Resources)
- 🤝 handshake (Mentorship)
- ⭐ star (Success Stories)
- ✉️ envelope (Contact)
- 🏠 home, ℹ️ info, ❤️ heart, 🚀 rocket

### 3. Social Media Links
**Location**: Site Settings → Social Links

**What's editable:**
- **Name**: Platform name (Instagram, LinkedIn, etc.)
- **URL**: Link to your social media page
- **Custom Icon**: Upload your own icon image (optional)
- **Icon Type**: Choose Font Awesome icon if no custom image
- **Icon Size**: 16-64 pixels

### 4. Background Slideshow
**Location**: Slideshow Images

**What's editable:**
- **Desktop Image**: Main image for computer screens
- **Mobile Image**: Optional phone-optimized version
- **Alt Text**: Description for accessibility

## 🖼️ Image Guidelines

### Button Preview Images
- **Best format**: Square images (1:1 ratio)
- **Size**: Aim for 800x800px or larger
- **File types**: JPG, PNG, WebP
- **Content**: Should relate to the button's purpose

### Slideshow Images
- **Desktop**: Landscape orientation, 1920x1080 or larger
- **Mobile**: Portrait orientation, 1080x1920 recommended
- **Quality**: High quality but optimized file size
- **Theme**: Should represent entrepreneurship, LMU, or student life

### Social Icons
- **Format**: PNG with transparent background preferred
- **Size**: 64x64px maximum
- **Style**: Match the overall design aesthetic

## ⚡ Quick Tasks

### Adding a New Button
1. Go to Site Settings → Action Buttons
2. Click "Add Action Buttons"
3. Fill in:
   - Title: "Workshop Series"
   - URL: "https://your-link.com"
   - Icon: "book"
   - Preview Image: Upload relevant image
4. Click "Save"
5. Click "Publish" to make live

### Updating Social Media
1. Go to Site Settings → Social Links
2. Find the platform you want to update
3. Change the URL to your new profile
4. Save and Publish

### Changing Background Images
1. Go to Slideshow Images
2. Click on existing image or "Add Slides"
3. Upload new desktop image
4. Optionally upload mobile version
5. Add descriptive alt text
6. Save and Publish

## 🔄 Publishing Changes

**Important**: Changes aren't live until you publish!

1. **Save**: Stores your changes as a draft
2. **Publish**: Makes changes live on the website
3. **Wait**: GitHub Pages takes 2-5 minutes to update

### Editorial Workflow
- **Draft**: Your changes are saved but not live
- **In Review**: Ready for approval (if enabled)
- **Published**: Live on the website

## 📱 Mobile vs Desktop

### Automatic Differences
- **Navigation**: Hidden on mobile for better experience
- **Buttons**: Stack vertically on phones, side-by-side on computers
- **Preview Images**: Only show on desktop
- **Text**: Automatically wraps on small screens

### Testing Your Changes
- **Desktop**: View on computer browser
- **Mobile**: Check on phone or use browser's mobile view (F12 → phone icon)

## 🛠️ Troubleshooting

### "I can't log in"
- Make sure you have write access to the GitHub repository
- Try clearing browser cache and cookies
- Contact the website administrator

### "My changes aren't showing"
- Did you click "Publish" (not just "Save")?
- Wait 5 minutes for GitHub Pages to update
- Hard refresh the page (Ctrl+F5 or Cmd+Shift+R)

### "Images won't upload"
- Check file size (keep under 5MB)
- Ensure file type is JPG, PNG, or WebP
- Try a different browser

### "The layout looks broken"
- Check that all required fields are filled
- Verify URLs start with https://
- Contact technical support if issues persist

## 🎨 Design Best Practices

### Button Guidelines
- **Titles**: Keep short and action-oriented ("Join Us", not "Click Here to Join Our Community")
- **Order**: Put most important actions first
- **Icons**: Choose icons that clearly represent the action

### Content Writing
- **Tagline**: Should be inspiring but concise
- **Alt Text**: Describe what's in the image for screen readers
- **URLs**: Always double-check links work

### Visual Consistency
- **Images**: Maintain similar style and quality across all uploads
- **Colors**: The system handles colors automatically
- **Spacing**: CMS handles layout - just focus on content
